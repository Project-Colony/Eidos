# Встановлення Eidos

Чотири шляхи. Colony встановлює один файл, `eidos-linux`, який і є всією програмою; решта дає `eidos` (командний рядок), `eidos-gui` і допоміжну програму статичного перегляду NIF поруч, а також обробник `nxm://`, завдяки якому кнопка «Mod Manager Download» на Nexus спрямовує завантаження до вашого екземпляра.

## Що потрібно спершу

| | |
|---|---|
| **Linux із FUSE** | `fusermount3` у PATH. Його постачає будь-який сучасний дистрибутив. |
| **Гра під Proton, запущена хоча б раз** | Steam створює Wine-префікс гри лише під час першого запуску, а Eidos працює всередині нього. |
| **`7z`** | Для встановлення архівів модів. У більшості дистрибутивів це `p7zip`. |
| **`par2`** (необов'язково) | Дані для відновлення PAR2 для резервних копій `eidos pack`. `par2cmdline` в Arch і Fedora, `par2` у Debian і Ubuntu. |

Ані root, ані демона, ані редагування `/etc/fuse.conf`, ані додавання до груп.
Eidos монтує у приватному просторі імен, що належить процесові гри.

## Через Colony

Знайдіть **Eidos** у [Colony](https://github.com/Project-Colony/Colony) і
встановіть його; оновлення приходять через лаунчер. Colony тримає один файл,
`~/.local/share/Colony/apps/Eidos/eidos-linux`. Запустіть його, і відкриється
вікно. Викликаний через посилання з назвою `eidos`, той самий файл є командним
рядком. Покладіть таке посилання у свій `PATH` і зареєструйте обробник
завантажень Nexus:

```bash
mkdir -p ~/.local/bin
ln -s ~/.local/share/Colony/apps/Eidos/eidos-linux ~/.local/bin/eidos
eidos nxm --register    # the site's Mod Manager Download button now reaches Eidos
```

Вікну посилання не потрібне: щоразу, коли воно запускає гру чи інструмент, воно
виконує власний файл як CLI. Попередньому перегляду моделей NIF потрібен
`eidos-nif-preview`, який є лише в пакеті випуску та у збірках із джерельних
кодів; без нього перегляд про це повідомляє, і більше ніщо не зачеплено.
Скеруйте Steam на сам файл, як описано нижче.

## Пакет випуску

Завантажте `eidos-linux-bundle.tar.gz` і його `.sig`, `.meta` та `.meta.sig`
з [останнього випуску](https://github.com/Project-Colony/Eidos/releases/latest)
і перевірте їх, як показує
[Політика підписування коду](../../README.md#політика-підписування-коду) в README. Потім:

```bash
tar xzf eidos-linux-bundle.tar.gz
cd eidos-linux-bundle
./install.sh
```

Типово встановлює в `~/.local/bin`. `--system` кладе у `/usr/local/bin`,
`--bindir DIR` - будь-куди. Повторний запуск - передбачений спосіб оновлення.
Пакету і `eidos-linux` потрібен Linux x86_64 з glibc 2.39 або новішою.

## Arch

```bash
cd packaging && makepkg -si
```

PKGBUILD збирає поточний `main` із джерельних кодів.

## З джерельних кодів

```bash
git clone https://github.com/Project-Colony/Eidos && cd Eidos
just build
just install
```

Для збирання з джерельного коду потрібні Rust 1.89 або новіший, `just`, CMake 3.20+, компілятор C++17 і Python 3 для тестів нативної допоміжної програми. Команди без `just` наведено в [інструкціях для нативної допоміжної програми](../../../../../crates/eidos-nif-preview/README.md). Зберіть Rust командою `cargo build --release --locked`, скопіюйте допоміжну програму до `target/release`, а потім запустіть `packaging/install.sh --from target/release`.

## Далі: скерувати на нього Steam

Eidos виконується *як* команда запуску вашої гри - саме так він встигає
змонтувати вигляд до її старту. У Steam: правий клац на грі -> Властивості ->
Параметри запуску:

```
~/.local/bin/eidos-gui %command%
```

Для Colony шлях - `~/.local/share/Colony/apps/Eidos/eidos-linux`. Натисніть
«Грати». Eidos відкриється на екземплярі цієї гри; встановлюйте моди,
сортуйте через LOOT, тисніть Run. Після виходу монтування зникає разом із грою, а
ваша інсталяція лишається точно такою, якою була.

Вказуйте абсолютний шлях - Steam не читає `PATH` вашої оболонки.

### Якщо ви віддаєте перевагу терміналу

```sh
eidos init skyrimse               # створити екземпляр (вкажіть теку, щоб зробити його портативним)
eidos install skyrimse mod.7z     # моди Simple / FOMOD / BAIN / root
eidos sort skyrimse               # відсортувати порядок завантаження через LOOT
eidos play skyrimse -- %command%  # запустити будь-що через об'єднаний вигляд
```

Кожна команда, що приймає ідентифікатор гри, приймає й теку портативного
екземпляра - див. [usage.uk.md](usage.md). Повна екскурсія там само.

## Необов'язково: FUSE passthrough

`sudo setcap cap_sys_admin+ep "$(command -v eidos)"` надає необов’язкову можливість, але не вмикає passthrough.
Вона ставиться на окремий бінарний файл `eidos` з пакета або зі збірки з джерельних кодів, ніколи не на
`eidos-linux`, який є також і вікном ([SECURITY.md](../../../../../SECURITY.md)).
`EIDOS_FUSE_PASSTHROUGH=1` — окремий перемикач під час запуску. Він **вимкнений типово, і майже напевно так і слід залишити**:
виміряно на Skyrim SE - він заважає грі відкривати власні архіви та додатки, тож
моди мовчки не завантажуються. Перемикач існує, щоб механізм можна було
перевірити знову, а не тому, що він рекомендований.

Подробиці й виміри, що стоять за цим рішенням, у
[troubleshooting.uk.md](troubleshooting.md).
