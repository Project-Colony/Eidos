# Розширення

Розширення додає до Eidos запис, не будучи частиною Eidos. Це TOML-маніфест, який
називає програму, плюс, щонайбільше, сама ця програма.

Маніфести живуть у `~/.config/Colony/Eidos/addons/`, по одному `.toml` на
розширення. Відкрийте теку через **View -> Extensions -> Open folder** і натисніть
**Reload** - без перезапуску.

## Чому в Eidos нічого не завантажується

Mod Organizer 2 завантажує додатки як спільні бібліотеки, а написані на Python
розміщує через Qt. Ані те, ані інше сюди не переноситься. Rust не має стабільного
ABI, тож спільна бібліотека, зібрана іншим компілятором - чи з іншим прапорцем
оптимізації, чи з іншим набором можливостей спільної залежності - це невизначена
поведінка, а не розбіжність версій. До того ж віджети Eidos є узагальненими на
етапі компіляції, тому бібліотека не змогла б побудувати віджет для повернення,
навіть якби ABI був стабільним.

Розширення — це програма, яку Eidos запускає з правами доступу вашого облікового запису до файлової системи. Установлюйте лише допоміжні програми, яким довіряєте. Ізоляція процесів і перевірка відповідей не забезпечують пісочниці операційної системи.

## Інструмент

```toml
id = "wrye-bash"
name = "Wrye Bash"
kind = "tool"
exec = "/opt/wrye/wrye-bash"
args = ["--data", "{data}"]
games = ["skyrimse"]        # опустіть, щоб для всіх ігор
description = "Bashed patch builder."
author = "you"
version = "1.0"
```

Він з'являється у **View -> Extensions** з кнопкою Run і стартує відокремлено -
Eidos на нього не чекає.

## Перевірка

```toml
id = "esl-count"
name = "ESL budget"
kind = "diagnose"
exec = "/home/me/bin/esl-count.sh"
args = ["{profile_dir}/plugins.txt"]
```

Вона виконується під час кожного оновлення й друкує по одному висновку на рядок:

```
level<TAB>title<TAB>detail
```

де `level` - це `problem`, `advice` або `ok`. Деталь необов'язкова. Усе, що не
починається з відомого рівня, ігнорується, тож вивід поступу й випадкові
попередження не здатні підняти рядок, схожий на власну перевірку Eidos. Висновки
з'являються у вкладці **Health** із префіксом назви розширення.

Перевірці дається три секунди. Та, що перевищить час, зупиняється й повідомляється
як проблема проти самої себе - вона виконується на тому самому оновленні, що йде
за кожним клацанням, тож зависла заморозила б вікно.

## Підстановки

І `args`, і `workdir` розгортають такі:

| Підстановка     | Що це                                        |
| --------------- | -------------------------------------------- |
| `{instance}`    | корінь екземпляра                            |
| `{mods}`        | `<instance>/mods`                            |
| `{downloads}`   | `<instance>/downloads`                       |
| `{overwrite}`   | `<instance>/overwrite`                       |
| `{profile}`     | назва активного профілю                      |
| `{profile_dir}` | тека активного профілю                       |
| `{game}`        | ідентифікатор гри, напр. `skyrimse`          |
| `{game_name}`   | відображувана назва гри                      |
| `{install}`     | тека встановлення гри                        |
| `{data}`        | тека `Data` гри                              |

Невідома підстановка лишається точно такою, як написана, а не спорожнюється, щоб
помилка провалювалася помітно, а не перетворювала `--out {typo}` на
`--out --next-flag`. Запуск інструмента, підстановки якого не всі розв'язуються,
відхиляється, і Eidos каже, яких бракує.

## Чого розширення не може

Розширення не може робити зворотні виклики до Eidos, реєструвати себе з архіву чи малювати власні віджети. Структуровані інсталятори протоколу 1 можуть повертати перевірені плани файлів і запитання з вибором; перевірку, підготовку в тимчасовому каталозі та публікацію контролює Eidos. FOMOD і BAIN залишаються нативними інсталяторами. Розширення перегляду та відомостей про збереження використовують той самий хост з обмеженнями на відповіді. Пріоритет зіставлення, записані відповіді CLI, обмеження та перевірки ідентичності під час повторного виконання описано у [специфікації протоколу й виконуваних прикладах](../../../../examples/extensions/README.md).
