# Расширения

Расширение добавляет в Eidos запись, не будучи частью Eidos. Это TOML-манифест,
называющий программу, плюс, самое большее, сама эта программа.

Манифесты живут в `~/.config/Colony/Eidos/addons/`, по одному `.toml` на
расширение. Откройте папку через **View -> Extensions -> Open folder** и нажмите
**Reload** - перезапуск не нужен.

## Почему в Eidos ничего не загружается

Mod Organizer 2 загружает плагины как разделяемые библиотеки, а питоновские
размещает через Qt. Ни то, ни другое сюда не переносится. У Rust нет стабильного
ABI, поэтому разделяемая библиотека, собранная другим компилятором - или с другим
флагом оптимизации, или с другим набором возможностей общей зависимости - это
неопределённое поведение, а не несовпадение версий. К тому же виджеты Eidos
обобщены на этапе компиляции, так что библиотека не смогла бы построить виджет
для возврата, даже будь ABI стабильным.

Расширение — это программа, которую Eidos запускает с правами доступа вашей учётной записи к файловой системе. Устанавливайте только вспомогательные программы, которым доверяете. Изоляция процессов и проверка ответов не обеспечивают песочницу операционной системы.

## Инструмент

```toml
id = "wrye-bash"
name = "Wrye Bash"
kind = "tool"
exec = "/opt/wrye/wrye-bash"
args = ["--data", "{data}"]
games = ["skyrimse"]        # опустить, чтобы для всех игр
description = "Bashed patch builder."
author = "you"
version = "1.0"
```

Он появляется в **View -> Extensions** с кнопкой Run и запускается отсоединённо -
Eidos его не ждёт.

## Проверка

```toml
id = "esl-count"
name = "ESL budget"
kind = "diagnose"
exec = "/home/me/bin/esl-count.sh"
args = ["{profile_dir}/plugins.txt"]
```

Она выполняется при каждом обновлении и печатает по одному выводу на строку:

```
level<TAB>title<TAB>detail
```

где `level` - это `problem`, `advice` или `ok`. Деталь необязательна. Всё, что не
начинается с известного уровня, игнорируется, так что вывод хода работы и
случайные предупреждения не смогут поднять строку, похожую на собственную
проверку Eidos. Выводы появляются во вкладке **Health** с префиксом из имени
расширения.

Проверке даётся три секунды. Превысившая срок останавливается и сообщается как
проблема против самой себя - она выполняется на том же обновлении, что следует за
каждым щелчком, поэтому зависшая заморозила бы окно.

## Подстановки

И `args`, и `workdir` раскрывают следующее:

| Подстановка     | Что это                                      |
| --------------- | -------------------------------------------- |
| `{instance}`    | корень инстанции                             |
| `{mods}`        | `<instance>/mods`                            |
| `{downloads}`   | `<instance>/downloads`                       |
| `{overwrite}`   | `<instance>/overwrite`                       |
| `{profile}`     | имя активного профиля                        |
| `{profile_dir}` | каталог активного профиля                    |
| `{game}`        | идентификатор игры, напр. `skyrimse`         |
| `{game_name}`   | отображаемое имя игры                        |
| `{install}`     | каталог установки игры                       |
| `{data}`        | каталог `Data` игры                          |

Неизвестная подстановка остаётся ровно такой, как написана, а не опустошается,
чтобы ошибка проваливалась заметно, а не превращала `--out {typo}` в
`--out --next-flag`. Запуск инструмента, у которого не все подстановки
разрешаются, отклоняется, и Eidos говорит, каких не хватает.

## Чего расширение не может

Расширение не может обращаться к Eidos через обратные вызовы, регистрировать себя из архива или рисовать собственные виджеты. Структурированные установщики протокола 1 могут возвращать проверенные планы файлов и вопросы с выбором; проверкой, подготовкой во временном каталоге и публикацией управляет Eidos. FOMOD и BAIN остаются нативными установщиками. Расширения предпросмотра и сведений о сохранениях используют тот же хост с ограничениями на ответы. Приоритет сопоставления, записанные ответы CLI, ограничения и проверки идентичности при повторном выполнении описаны в [спецификации протокола и исполняемых примерах](../../../../examples/extensions/README.md).
