# Установка Eidos

Три пути. Все дают `eidos` (командную строку), `eidos-gui` и вспомогательную программу статического предпросмотра NIF, а также обработчик `nxm://`, благодаря которому кнопка «Mod Manager Download» на Nexus направляет загрузку в вашу инстанцию.

## Что нужно заранее

| | |
|---|---|
| **Linux с FUSE** | `fusermount3` в PATH. Его поставляет любой современный дистрибутив. |
| **Игра под Proton, запущенная хотя бы раз** | Steam создаёт Wine-префикс игры только при первом запуске, а Eidos работает внутри него. |
| **`7z`** | Для установки архивов модов. В большинстве дистрибутивов это `p7zip`. |

Ни root, ни демона, ни правки `/etc/fuse.conf`, ни добавления в группы. Eidos
монтирует в приватном пространстве имён, принадлежащем процессу игры.

## Arch

```bash
cd packaging && makepkg -si
```

## Архив релиза

```bash
./install.sh
```

По умолчанию ставит в `~/.local/bin`. `--system` кладёт в `/usr/local/bin`,
`--bindir DIR` - куда угодно. Повторный запуск - штатный способ обновления.

## Из исходников

```bash
git clone https://github.com/Project-Colony/Eidos && cd Eidos
just build
just install
```

Для сборки из исходников нужны Rust, `just`, CMake 3.20+, компилятор C++17 и Python 3 для тестов нативной вспомогательной программы. Команды без `just` приведены в [инструкции для нативной вспомогательной программы](../../../../../native/eidos-nif-preview/README.md). Соберите Rust командой `cargo build --release --locked`, скопируйте вспомогательную программу в `target/release`, затем запустите `packaging/install.sh --from target/release`.

## Затем: указать на него Steam

Eidos запускается *как* команда запуска вашей игры - именно так он успевает
смонтировать вид до её старта. В Steam: правый клик по игре -> Свойства ->
Параметры запуска:

```
~/.local/bin/eidos-gui %command%
```

Нажмите «Играть». Eidos откроется на инстанции этой игры; ставьте моды,
сортируйте через LOOT, жмите Run. При выходе монтирование исчезает вместе с
игрой, а установка остаётся ровно такой, какой была.

Указывайте абсолютный путь - Steam не читает `PATH` вашей оболочки.

### Если вы предпочитаете терминал

```sh
eidos init skyrimse               # создать инстанцию (укажите папку, чтобы сделать её портативной)
eidos install skyrimse mod.7z     # моды Simple / FOMOD / BAIN / root
eidos sort skyrimse               # отсортировать порядок загрузки через LOOT
eidos play skyrimse -- %command%  # запустить что угодно через объединённый вид
```

Любая команда, принимающая идентификатор игры, принимает и папку портативной
инстанции - см. [usage.ru.md](usage.md). Полная экскурсия там же.

## Необязательно: FUSE passthrough

`sudo setcap cap_sys_admin+ep "$(command -v eidos)"` предоставляет необязательную возможность, но не включает passthrough.
`EIDOS_FUSE_PASSTHROUGH=1` — отдельный переключатель при запуске. Он **выключен по умолчанию, и почти наверняка так и надо оставить**:
измерено на Skyrim SE - он мешает игре открывать её собственные архивы и плагины,
поэтому моды молча не загружаются. Переключатель существует, чтобы перепроверять
механизм, а не потому, что он рекомендуется.

Подробности и измерения, стоящие за этим решением, в
[troubleshooting.ru.md](troubleshooting.md).
