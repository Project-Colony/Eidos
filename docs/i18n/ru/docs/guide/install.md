# Установка Eidos

Четыре пути. Colony устанавливает один файл, `eidos-linux`, который и есть вся программа; остальные дают `eidos` (командную строку), `eidos-gui` и вспомогательную программу статического предпросмотра NIF по отдельности, а также обработчик `nxm://`, благодаря которому кнопка «Mod Manager Download» на Nexus направляет загрузку в вашу инстанцию.

## Что нужно заранее

| | |
|---|---|
| **Linux с FUSE** | `fusermount3` в PATH. Его поставляет любой современный дистрибутив. |
| **Игра под Proton, запущенная хотя бы раз** | Steam создаёт Wine-префикс игры только при первом запуске, а Eidos работает внутри него. |
| **`7z`** | Для установки архивов модов. В большинстве дистрибутивов это `p7zip`. |
| **`par2`** (необязательно) | Данные для восстановления PAR2 для резервных копий `eidos pack`. `par2cmdline` в Arch и Fedora, `par2` в Debian и Ubuntu. |

Ни root, ни демона, ни правки `/etc/fuse.conf`, ни добавления в группы. Eidos
монтирует в приватном пространстве имён, принадлежащем процессу игры.

## Через Colony

Найдите **Eidos** в [Colony](https://github.com/Project-Colony/Colony) и
установите его; обновления приходят через лаунчер. Colony держит один файл,
`~/.local/share/Colony/apps/Eidos/eidos-linux`. Запустите его, и откроется окно.
Вызванный через ссылку с именем `eidos`, тот же файл становится командной
строкой. Положите такую ссылку в свой `PATH` и зарегистрируйте обработчик
загрузок Nexus:

```bash
mkdir -p ~/.local/bin
ln -s ~/.local/share/Colony/apps/Eidos/eidos-linux ~/.local/bin/eidos
eidos nxm --register    # the site's Mod Manager Download button now reaches Eidos
```

Окну ссылка не нужна: всякий раз, когда оно запускает игру или инструмент, оно
запускает собственный файл как CLI. Предпросмотру моделей NIF нужен
`eidos-nif-preview`, который есть только в наборе релиза и в сборках из
исходников; без него предпросмотр сообщает об этом, и больше ничего не
затрагивается. Указывайте Steam на сам файл, как описано ниже.

## Набор релиза

Скачайте `eidos-linux-bundle.tar.gz` и его `.sig`, `.meta` и `.meta.sig` из
[последнего релиза](https://github.com/Project-Colony/Eidos/releases/latest)
и проверьте их, как показано в разделе README
[Политика подписи кода](../../README.md#политика-подписи-кода). Затем:

```bash
tar xzf eidos-linux-bundle.tar.gz
cd eidos-linux-bundle
./install.sh
```

По умолчанию ставит в `~/.local/bin`. `--system` кладёт в `/usr/local/bin`,
`--bindir DIR` - куда угодно. Повторный запуск - штатный способ обновления.
Набору и `eidos-linux` нужен Linux x86_64 с glibc 2.39 или новее.

## Arch

```bash
cd packaging && makepkg -si
```

PKGBUILD собирает текущую ветку `main` из исходников.

## Из исходников

```bash
git clone https://github.com/Project-Colony/Eidos && cd Eidos
just build
just install
```

Для сборки из исходников нужны Rust 1.89 или новее, `just`, CMake 3.20+, компилятор C++17 и Python 3 для тестов нативной вспомогательной программы. Команды без `just` приведены в [инструкции для нативной вспомогательной программы](../../../../../crates/eidos-nif-preview/README.md). Соберите Rust командой `cargo build --release --locked`, скопируйте вспомогательную программу в `target/release`, затем запустите `packaging/install.sh --from target/release`.

## Затем: указать на него Steam

Eidos запускается *как* команда запуска вашей игры - именно так он успевает
смонтировать вид до её старта. В Steam: правый клик по игре -> Свойства ->
Параметры запуска:

```
~/.local/bin/eidos-gui %command%
```

Из Colony путь - `~/.local/share/Colony/apps/Eidos/eidos-linux`. Нажмите
«Играть». Eidos откроется на инстанции этой игры; ставьте моды,
сортируйте через LOOT, жмите Run. При выходе монтирование исчезает вместе с
игрой, а установка остаётся ровно такой, какой была.

Указывайте абсолютный путь - Steam не читает `PATH` вашей оболочки.

### Если вы предпочитаете терминал

```sh
eidos init skyrimse               # создать инстанцию (укажите папку, чтобы сделать её портативной)
eidos install skyrimse mod.7z     # моды Simple / FOMOD / BAIN / root
eidos sort skyrimse               # отсортировать порядок загрузки через LOOT
eidos play skyrimse -- %command%  # запустить что угодно через объединённый вид
```

Любая команда, принимающая идентификатор игры, принимает и папку портативной
инстанции - см. [usage.md](usage.md#инстанции-глобальные-и-портативные). Полная экскурсия там же.

## Необязательно: FUSE passthrough

`sudo setcap cap_sys_admin+ep "$(command -v eidos)"` предоставляет необязательную возможность, но не включает passthrough.
Она ставится на отдельный бинарный файл `eidos` из набора или сборки из
исходников и никогда не ставится на `eidos-linux`, который также является окном
([SECURITY.md](../../../../../SECURITY.md)).
`EIDOS_FUSE_PASSTHROUGH=1` — отдельный переключатель при запуске. Он **выключен по умолчанию, и почти наверняка так и надо оставить**:
измерено на Skyrim SE - он мешает игре открывать её собственные архивы и плагины,
поэтому моды молча не загружаются. Переключатель существует, чтобы перепроверять
механизм, а не потому, что он рекомендуется.

Подробности и измерения, стоящие за этим решением, в
[troubleshooting.md](troubleshooting.md).
